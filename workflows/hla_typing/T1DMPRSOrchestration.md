# T1DM PRS Orchestration Workflow

This workflow will generate a final T1DM PRS scores by mixing weighted HLA and T1DM PRS score. The HLA score is found by 1) running T1K to generate imputed HLA haplotypes, 2) running PHASE to get phased haplotypes and their corresponding weights, 3) scoring the phased haplotypes. The raw PRS is calculated using PLINK2 and then mixed with the scored HLA haplotypes.

## Output Parameters

| Type | Name | When | Description |
| :--- | :--- | :--- | :--- |
| File | vcf | When scoring from VCF | Input VCF or one generated by GLIMPSE imputation; absent when scoring from PGEN |
| File | score_summary | Always | TSV containing final T1DM score, the raw T1DM PRS score, HLA score, and HLA haplotypes |
